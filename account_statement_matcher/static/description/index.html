Bank Statement Matcher

Assign bank statement lines to invoices, bills, credit notes and payments — on Odoo Community

Odoo's bank reconciliation widget is part of account_accountant, an Enterprise module. On Community there is no way to assign an imported bank line to a document from the user interface, so statement lines pile up on the bank suspense account. This module rebuilds the missing step.

Suggests on import

Every new statement line is searched against the open receivables and payables as soon as it is created. Each suggestion carries a confidence and the rule that produced it, so you can see why it was proposed.

Searches again, later

A line that matches nothing today usually becomes matchable once the vendor bill, the credit note or the down payment has been entered. "Search again" picks those up at any time.

Refuses to guess

Ties are never resolved automatically. Each journal sets the confidence a suggestion needs before the bulk action books it; weaker matches are shown but must be confirmed one by one. Stored suggestions are re-checked before use, so a document settled in the meantime is refused rather than reconciled twice.

Works anywhere

Matching compares a document's own identifiers against the bank's free text, so any numbering scheme in any country works. The module depends on account alone and brings its own views, because Odoo Community ships none for bank statement lines.
